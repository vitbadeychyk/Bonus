# Списання бонусів ДК — макет

Інтерактивний макет екрана списання бонусів (розділ «ДК», «Маркетинг і реклама»). Дані вигадані, кнопки працюють лише на сторінці.

## Як опублікувати на GitHub Pages

1. На github.com натисніть **New repository**, назва, наприклад, `spysannia-bonusiv`. Видимість — **Public** (на безкоштовному тарифі Pages працює лише для публічних репозиторіїв).
2. На сторінці репозиторію: **Add file → Upload files**, перетягніть `index.html` і `README.md`, натисніть **Commit changes**.
3. **Settings → Pages**. У блоці *Build and deployment*: Source — **Deploy from a branch**, Branch — **main**, папка **/(root)**, **Save**.
4. За 1–2 хвилини вгорі сторінки Settings → Pages з'явиться посилання виду `https://<ваш-логін>.github.io/spysannia-bonusiv/`. Його й надсилайте.

## Як оновити

Завантажте новий `index.html` у той самий репозиторій (Add file → Upload files, із заміною). Сторінка оновиться за 1–2 хвилини.

## Важливо

Сайт GitHub Pages відкритий для всіх, хто знає посилання. У цій версії прибрано внутрішні назви таблиць, номери сторінок, логіни, номери карток і назви ТТ; пошуковим системам заборонено індексувати сторінку (`noindex`).
